# 🚗 Vehicle Service Management System

A comprehensive desktop application for managing vehicle service operations.

## Features
- 👤 Customer Management
- 🚗 Vehicle Tracking
- 🔧 Service Order Management
- 📄 Invoice Generation (PDF & Print)
- 📊 Dashboard with Analytics
- 📈 Reports
- 💾 Backup & Restore

## Technologies
- C# .NET 9
- Windows Forms
- Entity Framework Core
- SQL Server LocalDB

## Setup
1. Clone the repository
2. Open `VehicleServiceManager.sln` in Visual Studio
3. Change Connection String in VehicleServiceContext.cs
4. Build and run (F5)
